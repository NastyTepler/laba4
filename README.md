## Запуск

1. Открой проект в IDE (OpenIDE / IntelliJ IDEA).
2. Запусти `src/app/Main.java`.
3. Введи путь к входному текстовому файлу (например, `data/figures.txt`).
4. Введи путь к выходному бинарному файлу (например, `data/output.bin`).
5. Введи высоту цилиндра.

## Формат текстового файла

Одна строка — одна фигура. Поля разделяются символом `;`. Десятичные числа — через точку.

- Круг: `circle;радиус`
- Прямоугольник: `rectangle;ширина;высота`

Пример:

```
circle;5
rectangle;3;4
circle;2.5
```

## Поведение при ошибках чтения

Если строка текстового файла имеет неверный формат (неизвестный тип фигуры, не хватает параметров, число не парсится) или параметры фигуры некорректны (отрицательные, NaN, бесконечность), строка **пропускается** с сообщением в stderr, а чтение продолжается. Уже прочитанные фигуры сохраняются.

## Что реализовано

- **Задание 1** — интерфейс `Figure`, классы `Circle`, `Rectangle`, `Cylinder`. Своё непроверяемое исключение `InvalidFigureException`.
- **Задание 2** — методы `area()`, `perimeter()`, `volume()`, переопределён `toString()`.
- **Задание 3** — интерфейс `FigureStorage` с методами `read` и `write`.
- **Задание 4** — текстовая реализация `TextFigureStorage` (UTF-8, `java.nio`), проверяемое исключение `StorageException`.
- **Задание 5** — бинарная реализация `BinaryFigureStorage` через `ObjectOutputStream`/`ObjectInputStream`.
- **Задание 6** — сценарий в `Main`: чтение, вывод фигур, случайный цилиндр, запись в бинарный файл.
